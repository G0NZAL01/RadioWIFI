# 📻 RadiWiFi (Android APK)

![Android](https://img.shields.io/badge/Platform-Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Kotlin/Java](https://img.shields.io/badge/Language-Kotlin%20%2F%20Java-007ACC?style=for-the-badge)

Una aplicación nativa para Android diseñada para sintonizar tus emisoras de radio favoritas a través de la red WiFi, de forma rápida, fluida y sin complicaciones. Ideal para revivir la radio clásica con la estabilidad de las tecnologías de streaming actuales.

✨ **[¡Mira el vídeo de demostración en LinkedIn!](https://www.linkedin.com/feed/update/urn:li:activity:7467658251573198848/)**

---

## 🚀 Características Principales

* **Sintonización WiFi Estable:** Olvídate de las interferencias de la antena FM tradicional; audio nítido mediante streaming digital.
* **Añadir Emisoras Personalizadas:** Sistema dinámico para agregar tus propias cadenas mediante enlaces web de streaming de audio.
* **Interfaz Intuitiva y Moderna:** Diseñada para que puedas cambiar de emisora con un solo toque.
* **Bajo Consumo de Recursos:** Optimizada para funcionar en segundo plano sin devorar la batería de tu dispositivo.

---

## 🛠️ Cómo Funciona / Añadir Emisoras

La aplicación permite la carga y configuración de cadenas de radio utilizando enlaces de streaming directo. 

Para alimentar la lista de reproducción de la app o añadir nuevas cadenas, puedes utilizar las fuentes abiertas del excelente repositorio comunitario de **TDTChannels**:

1.  Accede a la lista oficial de emisoras en: [TDTChannels Radio](https://github.com/LaQuay/TDTChannels/blob/master/RADIO.md).
2.  Busca tu cadena de radio favorita (ej. *Onda Madrid, SER, COPE, etc.*).
3.  Copia el **enlace web de streaming** (formatos soportados habituales como `.m3u8`, `.mp3` o URLs de streaming directo).
4.  Pégalo en el apartado de configuración de la app ¡y listo para escuchar!

## 📲 Instalación (Descarga de la APK)

Al tratarse de un proyecto de código abierto, puedes probar la aplicación directamente en tu dispositivo Android sin pasar por la Google Play Store:

1.  Descarga el archivo `.apk`.
3.  Abre el archivo en tu dispositivo Android.
    * *Nota: Si es la primera vez que instalas una APK manual, tu teléfono te pedirá activar el permiso de "Instalar aplicaciones de fuentes desconocidas".*
4.  ¡Disfruta de la radio!
